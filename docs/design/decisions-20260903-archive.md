# 家庭档案实施决定（2026-09-03）

## 字段和授权

- 一期提供文字、日期、联系人、地址四类自定义字段，不预置身份证、银行卡等高敏字段。
- 字段默认仅管理员可见。管理员可改为家庭成员可见，或逐成员指定查看权限；非管理员修改内容还必须同时具备 `archive:EDIT` 和字段级“可编辑”授权。
- 新成员和朋友不会因为加入家庭而继承仅管理员或指定成员字段。无权账号查询单个字段时返回不存在，不暴露字段名和值。
- 字段定义与内容分别使用版本号。字段归档后和值一起从默认查询隐藏，但不物理删除。

## 加密和审计

- 所有档案值在 API 应用层使用 AES-256-GCM、随机 12 字节 nonce 和认证标签加密；数据库只保存密文、nonce、标签及密钥版本。
- 关联数据绑定家庭、字段及密钥版本，复制密文到其他家庭或字段后不能通过认证。
- `ARCHIVE_ENCRYPTION_KEY` 只放服务器 `apps/api/.env`，不进入数据库、镜像、Git、小程序或接口响应。需用 `openssl rand -base64 32` 生成并独立备份。
- 普通字段列表不返回任何明文；用户明确打开详情时才解密。查看、修改、字段授权变化和归档均写审计，但审计详情不含档案明文。
- 当前只读取配置的单一密钥版本；正式轮换前须先增加旧版本密钥环与重加密流程，不能直接替换环境变量。
