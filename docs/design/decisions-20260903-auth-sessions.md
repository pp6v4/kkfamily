# 登录会话实现决定（2026-09-03）

## 问题

原客户端只保存15分钟访问令牌。令牌过期时业务请求直接失败并清空家庭上下文，用户需要重复操作，且服务端没有主动退出或长期会话撤销能力。

## 实现

- 微信登录签发15分钟JWT访问令牌和30天随机刷新令牌。
- 数据库只保存刷新令牌SHA-256摘要，不保存或记录明文。
- 每次刷新都会消费旧令牌并签发新令牌；旧令牌在有效期内再次出现，撤销同一`familyId`会话族。
- 退出登录撤销当前刷新会话，对不存在的令牌也返回统一成功，避免泄露会话存在性。
- 客户端访问令牌过期时，多个请求共享同一个续期过程，并保留当前家庭；续期成功后原请求只重试一次。
- 刷新令牌无效时才重新调用`wx.login`，网络错误不伪装成令牌失效。

## 边界

服务端仍不接收微信`session_key`作为业务授权凭证。真实微信登录、并发刷新和会话撤销仍需在隔离PostgreSQL及真机环境保存验收证据。
