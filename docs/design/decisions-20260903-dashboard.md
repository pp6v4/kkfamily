# 非财务生活看板实施决定（2026-09-03）

## 指标口径

- 已发布菜谱：当前家庭状态为 `PUBLISHED` 的菜谱数。
- 完成餐次：所选时间范围内状态为 `COMPLETED` 的餐次；常选菜按 `mealId + recipeId` 的实际菜单行计数，不按点菜成员数重复累计。
- 当前待购：分别统计购物愿望、下次购买和需要补货，已购买不计入。
- 可见行程：只统计当前账号在所选时间范围内以 `ACTIVE` 或 `HISTORY` 身份参与的行程；待准备行李只统计这些行程中未排除的 `PENDING` 项。
- 待办完成情况：所选范围内创建且未取消、未归档的待办为分母，当前已完成为分子；分母为零时返回 `null` 并显示“暂无任务”，不显示虚假的 100%。

## 权限和产品边界

- 进入看板需要 `dashboard:VIEW`，每个指标还要重新检查其来源模块权限。无来源权限的指标整个字段不返回，客户端不以零值伪装。
- 看板不包含金额、预算、费用分摊、家务积分或成员勤劳排名；常选菜只评价菜，不评价人。
- 当前数据量很小，接口直接从业务表按权限聚合，不启用Redis缓存。后续确需缓存时，键必须包含账号、家庭、权限版本和时间范围，并处理源数据失效。
- 时间范围必须前小于后，最长366天；客户端提供近30天、近90天和近一年。
