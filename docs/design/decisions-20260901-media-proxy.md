# 一期私有图片代理方案（2026-09-01）

## 决策

一期沿用用户确认的单域名部署：微信小程序只访问 `pp6v4.com/api/`，不新增需要购买的业务域名。菜谱图片通过 API 代理上传至腾讯云 COS 北京私有桶，读取时先按当前家庭和菜谱权限换取 60 秒能力链接，再由同一 API 代理返回图片。

## 安全与业务边界

- COS SecretId、SecretKey只配置在服务器环境变量，不进入小程序、Git、镜像或接口响应。
- 客户端不能提交或获得COS objectKey；服务端以家庭、资源和随机UUID生成对象键。
- 上传申请绑定菜谱ID、家庭ID、申请成员和菜谱version；上传期间菜谱被修改时，确认返回409，不把图片绑到过期版本。
- 只接受JPG、PNG、WebP，最大8MB；服务端核验HTTP类型、真实字节数、文件签名字节和SHA-256，确认时再通过COS HEAD核对元数据。
- 草稿允许无图；从DRAFT发布前必须已有READY封面。既有无图PUBLISHED数据不自动删除，但重新发布必须补图。
- 停用或撤权成员不能申请新的读链接；已签发链接最多继续有效60秒，符合A35，不宣称立即撤销已经外发的能力链接。

## 部署影响

Nginx `/api/` 允许最大9MB请求。API设置 `MEDIA_DRIVER=cos` 后才启用真实COS；同时配置 `COS_BUCKET=family-life-pp6v4-1303887403`、`COS_REGION=ap-beijing`及CAM最小权限密钥。未配置时接口返回503，不能假装上传成功。

代理方案会占用云服务器3Mbps带宽，但家庭规模和单图8MB上限下可先接受。真实使用发现图片流量成为痛点后，再评估COS直传与小程序域名登记，不提前增加部署复杂度。
