# 一期库存自动增减范围确认（2026-09-01）

确认来源：用户在本任务中明确提出，做饭减少库存、购物增加库存等复杂逻辑现阶段先不做，实际使用并找到痛点后再增加；例如剩余几根葱、一次做饭消耗多少，持续维护会很麻烦。

## U14：一期确认结论

- 完成做饭只更新餐点状态，不修改任何库存数量。
- 勾选“买到了”只保存购物记录，不自动增加库存。
- 家中库存仍可由获授权成员手工登记、核实和调整。
- 点餐仍展示菜谱需求与家中库存对照；结果仅辅助判断，不代替人工决定。
- 菜单确认快照、多人想吃汇总、缺料加入购物清单和“再买一次”继续保留。
- 自动消耗、自动入库及精细库存批次核销从一期验收范围移出，待真实使用反馈后重新设计，不能在界面中暗示已经发生。

## 对既有设计的影响

本决定是对 `contract-details.md` D05/D06 中自动库存增减工程方案的后续范围调整。既有 A18“实际消耗扣减”以及购买后入库关联不再作为一期完成条件；保留为未来需求样例。当前 `POST /meals/:id/complete` 只接收 `expectedVersion`，幂等完成餐点；购物项没有入库接口。

本决定不取消人工库存流水、未知库存、调料有/无/未知、不同单位不换算及缺料辅助判断。
