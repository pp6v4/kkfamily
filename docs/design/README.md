# 设计评审资料

日期：2026-08-31。范围是设计补齐，不是正式版上线承诺。

- [实施契约](contract-details.md)：13组用户要求、15个设计章节；覆盖导航、权限、餐饮、购物、行程分组、行李、地图、媒体、日历待办、收藏、档案、看板和通知。
- [目标字段字典](target-data.md)：现有模型的扩展、新实体字段、唯一键/外键、迁移顺序，明确不等于已执行DDL。
- [验收追踪](acceptance.md)：42条输入和预期明确的用例，全部默认NOT_RUN，不以文档存在冒充测试通过。
- [页面与交互设计](interaction-design.md)：P01～P36页面目录、共用状态、跨模块操作出口及完整自定义行李流程。
- [行李交互原型](packing-prototype/index.html)：本地内存演示；用户自命名模板、套用预览、独立清单、分工和只读状态。
- [原型验证记录](prototype-verification.md)：13条模型测试及浏览器检查；不等同真实业务接口验收。

自定义模板不内置物品、不按“烧烤”等名字分支。已有模板套用逻辑仍需完成历史来源名称、小组分工和完整权限边界后才能覆盖全部目标设计。

Word评审包位于工作区outputs/design-review-20260831；该目录保留八份分立文档、文本附件和文件SHA256清单。旧版不删除。

待用户评审：R01确认后改单、R02主动撤权与历史访问、R03档案字段与工单用途。外部联调：备案/HTTPS实际状态、微信账号、地图Key、订阅模板。文档结构审计可自动完成，缺少LibreOffice时页面视觉审计必须明确标记未完成。
