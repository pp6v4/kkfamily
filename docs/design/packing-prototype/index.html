把小日子，
装进行李里。

常带的东西存成模板，每趟出发独立准备。

你的模板，你来命名。

名称不决定内容。写“烧烤”，也只会保存你亲手填的物品；不自动添加桌子、烤炉或炭。

可以这样试一遍

  1. 新建模板，命名“烧烤”，只填1、2、3。
  2. 打开本次行李，预览并套用模板。
  3. 再次套用，检查不会重复增加。
  4. 改模板名称，再看本次行李的来源名称仍保留旧值。
  5. 分配示例小组和负责人，勾选已准备。
