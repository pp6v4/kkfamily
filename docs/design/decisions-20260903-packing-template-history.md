# 行李模板历史与并发编辑落地（2026-09-03）

## 核对发现

- 设计要求删除模板项时保留稳定ID，旧行程继续展示套用当时的模板名和物品名。
- 旧实现会物理删除`PackingTemplateItem`，且`PackingTemplate`没有版本号，两个管理者同时编辑可能静默覆盖。

## 一期行为

- `PackingTemplate`和`PackingTemplateItem`均保存`version`；修改必须提交模板`expectedVersion`，旧版本返回409。
- 编辑时省略的旧物品写入`archivedAt`，不物理删除；列表和新套用只读未归档项。
- 套用时保存模板名、物品名、数量、单位和备注快照；后续改名、删项和归档不改旧行程。
- 编辑页可将描述、数量、单位和备注显式清空，不会因为空值在JSON中丢失而残留旧值。

## 验证边界

`A28`集成用例覆盖：首次套用、改名、删项软归档、旧版本409、旧行程快照不变、新行程只套有效项，以及归档模板不可再套用。
