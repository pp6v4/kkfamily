# 一期家庭待办与请求范围（2026-09-02）

- 家庭待办支持TODO和REQUEST；REQUEST是家庭成员之间的请求，不冒充软件客服工单。
- 字段包含标题、说明、负责人、优先级、截止时间、提醒计划、状态和版本，不增加家务积分、排行或财务字段。
- tasks:EDIT成员可创建并默认分配给自己；只有tasks:MANAGE可分配或改派给其他家庭成员。
- 负责人或管理员可开始、完成、取消；完成或取消后重新打开必须填写原因。
- 创建、内容更新、状态变化和评论都保留TaskHistory，历史记录不提供普通修改接口。
- 有截止时间且未取消的任务由日历从Task真数据动态聚合；取消后不再出现在日历，但历史不删除。
- reminderAt在一期当前阶段只是提醒计划。站内Inbox、outbox、worker及微信订阅消息未接入前，界面不得声称提醒已经发送。
