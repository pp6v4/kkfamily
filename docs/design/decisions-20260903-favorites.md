# 收藏与灵感实施决定（2026-09-03）

## 一期边界

- 支持文字、图片和链接三类收藏；标题、正文、来源链接、标签及可见范围由成员手工填写。
- 来源链接只接受 `http` 或 `https`，后端不访问、不解析、不抓取第三方网页，避免把不可靠内容或内网请求引入家庭服务。
- `PRIVATE` 只对创建者和收藏管理员可见；`HOUSEHOLD` 对具有收藏查看权限的家庭成员可见。
- 创建者可维护和归档自己的收藏，收藏管理员可维护家庭全部收藏；所有写入使用版本号防止覆盖并写审计记录。
- 图片沿用私有媒体链路，经同域 API 上传和短期读取能力链接访问，不暴露 COS 对象键。

## 转换规则

- 收藏可转换为菜谱草稿或家庭待办。转换请求必须由用户再次确认标题，可补充说明，并携带幂等键。
- 菜谱转换只创建 `DRAFT`，食材、调料、做法和封面均不猜测。即使随后添加封面，未填写食材或做法仍不能发布。
- 待办转换创建分配给操作者本人的普通待办，来源正文、说明和链接仅作为描述，不触发网页抓取。
- 原收藏始终保留；相同成员、相同幂等键的重试返回同一个目标，不能重复创建。
- 归档收藏不会删除已经转换出的菜谱或待办。

## 暂不纳入

- 自动网页摘要、网站爬取、第三方内容同步。
- 自动识别图片内容、自动生成菜谱食材或做法。
- 收藏公开分享及家庭外链接。
