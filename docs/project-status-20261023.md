## 2. 0.1.3改了什么

与0.1.2相比是六项闭环修复加一项审查补丁，不是新增完整大模块：

| 编号 | 使用者能感知的变化 | 实现与不变约束 |
| --- | --- | --- |
| F01 | 数量未填时，购物和人工库存仍能看到kg/g等单位 | null不当0、不自动换算；调料仍只判断有无，不自动扣增库存 |
| F02 | 准备组改名后，同屏行李标签同步更新 | 小组只保存一次，重读行程和行李；保留原ID、版本、负责人及状态；读取失败明确为“已保存但刷新失败” |
| F03 | 已有待办也能单独取消提醒或截止日期 | 清除传null；未改另一时间保留其完整精度；取消编辑不提交 |
| F04 | 收藏转换成功但跳转失败后，可以重试打开原草稿 | 保留同一幂等键，不创建第二份，不丢来源收藏；菜谱草稿仍需补材料做法 |
| F05 | 档案旧请求不覆盖新草稿，也不重新展开已隐藏的明文 | 新建/编辑/取消使旧响应失效并清明文；服务器加密、字段ACL和审计不变 |
| F06 | 行李新增/改派与成员撤权竞争时，不留下给失效成员的新责任 | 授权、行程/组成员校验、写入及返回重读在同一Serializable事务，受限冲突重试；模板套用/移除使用同一保护 |
| RV01 | 准备组保存后两路读取先网络失败、后鉴权失败，也清空当前私有视图 | 每路独立检查页面作用域/读取代次；旧账号、旧行程或旧请求的403不能误清新视图 |

源文件、复测步骤与修复前后证据见[0.1.3变更清单](release-notes-0.1.3.md)、[批次核对](closure-followup-20261022.md)和[独立代码审查](code-review-20261023.md)。0.1.2的B01～B04不是本版新修复，不能重复计入。
