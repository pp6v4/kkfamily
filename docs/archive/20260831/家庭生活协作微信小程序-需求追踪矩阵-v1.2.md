## 自定义行李模板验收用例

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| PACK-T01 任意命名 | 模板名“烧烤”，物品1/2/3；再建模板名“摄影” | 两者完全等价，系统不自动增加任何物品 |
| PACK-T02 多模板 | 同一行程套用“烧烤”和“摄影” | 两组物品均进入本次清单，来源可追溯 |
| PACK-T03 独立快照 | 套用后修改模板物品数量和名称 | 已套用行程保持原值，新行程使用新值 |
| PACK-T04 重复套用 | 同一模板连续套用两次 | 第二次不产生重复项，返回跳过数量 |
| PACK-T05 手工物品 | 行程内添加一次性物品 | 来源字段为空，不写回任何模板 |
| PACK-T06 负责人 | 尝试指定非行程成员 | 拒绝；指定行程成员后成功 |
| PACK-T07 历史 | 行程完成后归档模板 | 历史清单、负责人和已准备状态仍可见 |
