## 手机复测顺序

1. 重新进入新体验版；浏览“去点餐→菜谱→待做菜单”，检查文案，再点一道菜并撤回。
2. 分别选择主食/炒菜/海鲜，核对菜谱归属；分类改名后再检查。
3. 打开家中库存，新增时存放位置应为空，输入后字段标题仍可见；编辑旧记录应保留原位置。
4. 新建菜谱输入名称、多项食材/调料/步骤，切到其他应用找图片后返回，逐项核对内容。
5. 未保存时退出小程序再进入，应提示继续编辑；选择继续后内容和可恢复图片仍在。
6. 保存后再次新建不应重复恢复已保存内容；校验失败或上传失败则应保留输入。

本批不包含Q01地图阶段线型修复。分类停用会阻止新菜谱选择该分类，但已有菜谱保留；如测试该动作，请先阅读页面确认提示。
