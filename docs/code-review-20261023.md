## 确认发现

### RV01 / P2：并行重读先普通失败时吞掉后到的鉴权失败

位置：`apps/client/src/pages/camping/index.vue`的`refreshTripAndPacking`。准备小组保存成功后，同时重读行程和行李；原代码仅在`Promise.all`首次拒绝时进入统一异常处理。

真实SFC内存复现：行程重读先网络失败、行李重读随后403，或两路相反；原视图仍保留已加载的行程、物品和身份，仅提示“已保存但刷新失败”。预期后到的当前作用域401/403/404同样立即清空私有视图，不等待另一路、不再次写入小组；已经隐藏/切换身份/切换行程或被新读取取代的旧错误不得清空新视图。

处理状态：已修复。每路拒绝独立检查原页面/身份/行程作用域及对应读取代次，当前401/403/404立即清空私有视图；已经过期的拒绝不再向外层冒充当前鉴权错误。仍保留普通失败“已保存但刷新失败”的说明，不等待另一挂起请求才清理，也不再次写入小组。未修改后端权限或自动库存边界。
