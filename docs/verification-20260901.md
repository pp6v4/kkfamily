## 隔离环境

- 运行位置：云服务器上的独立 Docker 网络、独立 PostgreSQL 测试容器及测试 schema。
- 生产 `/opt/family-life`、生产 PostgreSQL、Redis 与线上容器未执行迁移、重启或业务写入。
- 身份数据均由测试生成，微信登录未调用真实微信接口。

关键范围断言：完成餐点重复提交保持幂等，且库存数量不变、没有自动消耗流水；购物项标记已购买和复购均不改变库存。缺料项由服务端按已确认菜单快照及当前人工库存重新计算，客户端不能自行提交任意数量。菜谱编辑使用版本号防止覆盖他人修改，草稿详情不向只有查看权的账号暴露；已确认餐单继续读取冻结快照，不随菜谱后续修改漂移。

私有图片关键断言：无图草稿可保存但发布被拒；客户端得不到COS objectKey；上传申请绑定家庭、成员、菜谱及version；伪造格式、大小、Content-Type和checksum被拒；重复确认返回同一资产；撤权后不能生成新读链接，已生成能力链接保留60秒窗口。首次执行发现路径参数承载JWT触发414，改成查询参数后在原测试schema和全新schema均完整通过。
