## 2. 新确认的问题与最小修正

| 编号 | 修复前可重复反例 | 修正及预期 |
| --- | --- | --- |
| RA01 点餐读取失败被当成未创建 | 撤回已成功→本餐查询或库存比对503→清掉本餐，菜谱按钮变成可点“点这道菜”；再次点击可重新创建/加菜 | 区分“餐点尚未加载”和“确认没有该餐”；未知期间禁写并保留明确重读入口。已读取的餐点不因可选库存失败丢失；清空不可信库存对照，说明“操作已保存但刷新失败”。401/403/404失效与普通库存网络错误分别处理 |
| RA02 权限拒绝后旧私有界面残留 | 档案保存403后仍显示已展开明文及编辑按钮；待办/收藏对应拒绝仍保留旧详情和编辑权限。旧待办取消弹框确认时还可能作用于后来选中的任务 | 当前页面/账号作用域的401/403清私有内容、草稿和旧权限；资源404按来源清理。旧账号、隐藏页或旧读取的拒绝不影响新视图；普通409保留有效草稿和原版本。待办取消确认同时比对原身份、任务ID及版本，并复核当前权限 |
| RA03 收藏已保存后结果丢失 | 新建收藏成功→重读列表失败，只剩网络错误，已保存目标ID丢失 | 保存成功后保留目标身份/ID，明确已保存及读取失败；重试读取原目标，不再次POST创建。F04转换幂等键、F05档案草稿代次仍受原回归保护 |
| RA04 模板写成功后重复提交 | 新建模板已提交→列表刷新失败，表单仍被当作新建；重试同名409；编辑则使用旧version409 | 先采纳写回对象ID/version并关闭保存表单；明确已保存，重读按钮只GET；保留从行程往返的目标，迟到/拒绝仍受作用域保护。开启另一份新建/编辑草稿即取消旧恢复标记，重读不能覆盖新草稿或误导航 |
| RA05 排序后旧路线没有操作入口 | A→B→C已有AB/BC，改序A→C→B；旧路段仍在地图，但只给相邻节点渲染按钮，旧路段无法编辑/移除 | 非相邻现存路段独立展示并复用原修改/确认删除操作及版本；只读历史不出现编辑按钮。不自动删除路段、不重置staleAt、不开放终态业务编辑 |
| RA06 行李未知数量丢单位 | 数量null、单位“箱/顶”时quantityText返回空串 | 保留“数量待确认”及已填单位，不把null当0，不换算或自动调整库存 |
