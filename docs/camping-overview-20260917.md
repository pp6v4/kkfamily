# 露营地图首屏差异修复（2026-09-17）

需求：露营界面首先是中国地图，地图展示可访问行程及出行状态。

发现：旧实现没有地点时只显示地图表情占位；已有地点标记没有点击入口。已改为有露营查看权限且页面可见时加载真实原生地图，无地点使用中国区域中心坐标与缩放4；不申请用户当前位置。点击标记或文字标签进入对应行程，再由既有接口复核成员权限。标记ID使用扁平列表唯一编号，避免单趟超过1000地点后与下一趟碰撞。

保留原待出行闪烁虚线、进行中/已完成实线箭头；补充直线是地点连线示意而非道路导航的说明。“我的家”提醒入口不再宣称提供微信订阅设置。

事件及属性采用[uni-app官方map文档](https://uniapp.dcloud.net.cn/component/map.html)的`markertap`、`labeltap`、`markerId`与`include-points`约定。

验证：`pnpm check:client`通过（lint、vue-tsc、249/249）；新增用例检查空地图中心、模板不依赖地点数量、1002个标记无重复ID、无效标记不请求、正确行程入口及隐藏后不响应。微信构建成功，同步原`outputs/mp-weixin`目录，78文件SHA256一致、14页面完整、私有配置保留。编译模板包含两个原生标记事件与示意说明。

本批只有客户端改动，不重新部署后台、不迁移数据库、不上传微信平台。真机地图渲染及动画仍待验收；“先选目的地再创建行程”的完整流程与道路规划尚未补齐，不因本次测试通过就计为完成。COS与双账号验收沿用首发检查清单，不宣称其状态已改变。
